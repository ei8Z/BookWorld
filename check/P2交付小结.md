## 4. 新命令与参数

| 命令 | 说明 |
|---|---|
| `bookctl search <q> --semantic` | 稀疏向量召回；`mode` 字段区分 `fts`/`semantic` |
| `bookctl check [--range A-B] [--foreshadow-stale N] [--deep]` | 三类一致性检查；`--foreshadow-stale` 默认 30 章 |
| `bookctl ingest ... --no-extract` | 只入库 + 建索引，跳过 LLM 抽取（省钱） |
| `bookctl extract --range A-B` | 批量补抽取，完成后自动重建实体索引 |

## 5. 设计说明与已知边界

1. **稀疏向量的能力边界（计划要求明确文档化）**：
   - 有效：**共享词汇**的改写 —— "机房/服务器" ↔ "服务器机房"，实测余弦 0.52 vs 无关文本 0.05；
   - 有限：**纯同义改写** —— "电脑" ↔ "计算机" 实测余弦 **0.0**，即完全召回不了。
     这是字符 n-gram 词形相似的固有特性，不是缺陷。要覆盖它必须接 dense embedding，
     故预留了 `Embedder` 协议（`memory/vector.py`），文档里写了接 bge-small-zh 的示例，
     依赖做成可选 extra、不装也能跑（遵守计划 §7 的零重依赖约束）。
2. **semantic 路径不自动回退到 FTS**：两者 score 不可比（余弦 0~1 vs bm25 取负），
   混在一起会让 score 失去意义。调用方想对比就调两次。
3. **状态检查的在场判定加了最小提及次数（默认 2）**：正文里只被提一次名字
   （比如回忆里提到）不算"在场矛盾"，避免大量假阳性。单字名 NPC 不参与该判定。
4. **伏笔检查的阈值边界**：`gap > threshold` 才报（`gap == threshold` 不报），
   `--foreshadow-stale` 可调；没写 `planted_chapter` 的伏笔跳过（无法判断）。
5. **`--deep` 无 Key 时**：不崩、纯规则结果照常返回，并追加一条 `kind=ability, severity=low`
   的说明，告知跳过了模型深度检查。

## 8. 独立审查与缺陷修复（第二轮）

独立 Agent 对 P2 做了对抗性验证（12 项复现脚本 + 向量数学/边界数值/CLI 契约/回归）。
它确认 P2 主干与验收①成立、四套测试确定性全绿、P0/P1 无回归，但报出 12 项缺陷。
处置如下。

### 必修（已修 + 回归测试）

| # | 缺陷 | 修法 |
|---|---|---|
| D4 高 | **extract 不幂等**：同一轮跑两次 extract，相对增量（好感 +5、经验 +10、记忆 +1）会应用两遍；且会重抽 ingest 阶段已抽过的轮次 | `session_history` 新增 `extracted_at` 列（幂等迁移 + 索引）；`extract` 默认只处理 `extracted_at IS NULL` 的轮次，跳过已抽取的并在 warnings 里说明；`--force` 才允许重抽；ingest 抽取成功时打标记 |
| D1 中 | **player.hp/en 越界检查永不触发**：只读 `story_state_json`，而生产写入的 `StoryState.model_dump()` 根本没有 hp/en 字段 | `check_state` 改为**读 player 表**；测试也从"往 JSON 里塞 hp"改成"改 player 表"，不再账面通过 |
| D3 中 | NPC 名字子串假阳性：`is_present=0` 分支缺 `len>=2` 守卫，NPC「林」被正文里的「林越」误判 | 两个分支统一加长度守卫（空名也一并挡掉） |
| D2 中 | **哈希碰撞**：`FNV1a(信息) % 4096 == FNV1a(动作) % 4096`，无关两字文档对查询"信息"得 **score=1.0** 压过真实命中 | `DIM` 4096 → **65536**；`cosine` 增加 `min_shared`，语义检索要求 **≥2 个共享特征桶**；实测碰撞对全部归零，真实改写仍 0.50；新增 `--min-score` 供调用方过滤弱相关 |

### 已修的低优先项

| # | 缺陷 | 修法 |
|---|---|---|
| D6 | `--deep` 把模型返回的 `kind=banana / severity=critical / refs="not-a-list"` 原样透传，破坏 §5 枚举 | 按 `VALID_KINDS`/`VALID_SEVERITIES` 白名单收敛，refs 强制成 `list[dict]`，合并后重新排序 |
| D7 | 非法时间（`08:99`）被静默当 00:00，造出"时间倒挂"假阳性 | 找到时刻但数值非法时直接返回 None，跳过该轮 |
| D8 | `_ISO_TIME` 是死代码，`"2026-06-22 14:00"` 里的时刻被丢弃 → 同日倒退漏报 | 时刻解析改为先看 `time_str` 再看 `date_str` 内嵌 |
| D9 | 时间线按全库 id 序比较（计划写的是"同一卷内"），跨卷回退误报 | 按 `volume` 分组比较；无卷信息时退化为全局序 |
| D10 | `--range 5-1` 静默空结果、`--foreshadow-stale -1` 被接受 | 都改为 usage 错误（退出码 2） |
| D11 | 空名 NPC 报"出现了 8 次"（`str.count("")` = 长度+1） | 空名与单字名一并跳过 |
| D12 | `cosine` 自身相似度偶发 1.0000000000000002 | 结果夹紧到 `[0, 1]` |
